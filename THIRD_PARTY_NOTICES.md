# QR dependencies

CleanCity uses these Apache-2.0 licensed libraries through Gradle:

- ZXing core 3.5.3 — https://github.com/zxing/zxing
- ZXing Android Embedded 4.3.0 — https://github.com/journeyapps/zxing-android-embedded

See their upstream LICENSE/COPYING and NOTICE files for copyright notices and license terms. The integration uses the published ScanContract API and QRCodeWriter; no recognition model is fetched at runtime.
